# Reinforcement Learning

A hands-on journey into reinforcement learning, exploring fundamental algorithms, mathematical foundations, and practical implementations.

## Topics
- Q-learning
- Deep Q-Networks (DQN)
- Policy Gradients (REINFORCE)
- Future reinforcement learning algorithms and experiments

## Tech Stack
Python, PyTorch, Gymnasium, NumPy, Matplotlib

## Structure
- `enviroment.ipynb` — Environment exploration
- `q_learning.ipynb` — Tabular Q-learning
- `dqn.ipynb` — Deep Q-Networks
- `REINFORCE.ipynb` — Policy gradients

More algorithms, experiments, and implementations will be added as I progress through reinforcement learning.
